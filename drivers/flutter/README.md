# Flutter

Flutter driver for [Bombadil](https://github.com/antithesishq/bombadil), using
an in-app bridge to capture semantics and apply UI actions through Flutter's
headless engine.

The Compass example requires x86_64 Linux, Flutter, fonts, and a Bombadil build
with `external` support. See [Get started](../../docs/GET_STARTED.md#dart-flutter)
for native setup or the optional Nix shell.

See the [entrypoint](examples/compass_app/bombadil_main.dart),
[setup script](examples/compass_app/setup.sh), and
[specification](examples/compass_app/spec.ts).
